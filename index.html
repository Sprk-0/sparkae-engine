Method
EXAMINE

Determine if: “prohibited account types are defined.” The SSP enumerates permitted account types in §3.2 but never lists the types the system prohibits, so the objective is only partially covered.

Evidence cited: SSP §3.2 “Account Types” (BM25 0.74); AC-Policy.docx §4.1.

Remediation: Add an explicit list of prohibited account types (shared, guest, anonymous) to SSP §3.2 and cross-reference the account-management policy.

Why a CUI program can use it at all.
Cloud-native tools cannot follow you inside the boundary. This one does not need to.
Deterministic
No wall-clock, no randomness, no model drift. The same package yields the same findings — reproducible on demand for an assessor or an authorizing body.
Zero data out
Default mode (LLM_PROVIDER=none) makes no outbound calls: no HTTP, no DNS, no CDN, no telemetry. CUI never transits a vendor cloud because there is none in the path.
Integrity gate
A verdict of Satisfied must be grounded in cited evidence or it is blocked. That holds in every mode, including the opt-in LLM ones.
Machine-readable
Native OSCAL 1.1.2 assessment-results and POA&M, validated against the NIST schema. Structured from the start, whatever shape the mandate takes.
Three deployment modes. You choose what leaves your network.
LLM is always opt-in. When a model is on, it produces the determination directly; the 7-gate engine does not run alongside it.
