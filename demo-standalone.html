Step 2 · Connect your evidence sources

Map your existing tools to FedRAMP artifact categories

Tab §09 Data Sources shows two tiers of connectors. Tier 1 is evidence sources (scanners, IdP, cloud posture, doc repos). Tier 2 is GRC platforms you may already use — every connector defines a schema mapping from its native fields into the SPARKAE canonical evidence record (OSCAL-aligned), then onward to the FedRAMP deliverable per fedramp.gov/documents-templates.

Tier 1 · Doc reposDrive · GitHub · Confluence · Box → SSP · IaC · policies · ATO letters
Tier 1 · WorkflowJira → POA&M · CM-3 changes · IR-4 incidents
Tier 1 · EvidenceTenable · Okta · AWS Config · Splunk → KSI evidence + ConMon
Tier 2 · GRC peersServiceNow GRC · Drata · Vanta · ZenGRC · OneTrust · Hyperproof · AuditBoard · Archer
Tier 3 · CustomJSON · CSV · PDF/OCR · webhook for unstructured / non-conforming tools

Tier 3 uses namespaced extensions (per fedramp.gov OSCAL prop pattern) so vendor-specific data round-trips losslessly without breaking canonical guarantees. Click any connector card to view its schema mapping.
